## 历史案例

### 案例 1
- **日期**: 2026-05-19_103843
- **来源 PR**: Demo: 用户登录模块
- **文件**: demo/sample_pr.py:175-176
- **描述**: _TOKEN_CACHE 是模块级全局字典，被 auth_require_permission 装饰器使用。全局可变状态会导致以下问题：1) 线程不安全，多线程环境下可能出现数据竞争；2) 测试困难，测试之间会相互影响；3) 难以追踪状态变化。
- **修复**: 使用依赖注入将缓存实例传入装饰器，或使用线程安全的缓存实现（如 Redis 或 cachetools.TTLCache）。避免使用模块级可变全局变量。
