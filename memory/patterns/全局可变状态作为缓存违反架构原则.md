## 历史案例

### 案例 1
- **日期**: 2026-05-19_101524
- **来源 PR**: Demo: 用户登录模块
- **文件**: demo/sample_pr.py:175-176
- **描述**: _TOKEN_CACHE 是模块级全局字典，被 auth_require_permission 装饰器内部使用。全局可变状态导致：1) 线程不安全，多线程环境下可能产生竞态条件；2) 测试困难，状态在测试用例间共享；3) 无法控制生命周期。
- **修复**: 1) 使用 functools.lru_cache 或 cachetools.TTLCache 替代手动字典缓存；2) 将缓存逻辑封装为独立的 CacheService 类，通过依赖注入使用；3) 考虑使用 Redis 等外部缓存服务。
