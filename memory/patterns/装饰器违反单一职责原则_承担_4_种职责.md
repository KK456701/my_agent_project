## 历史案例

### 案例 1
- **日期**: 2026-05-19_103843
- **来源 PR**: Demo: 用户登录模块
- **文件**: demo/sample_pr.py:128-155
- **描述**: auth_require_permission 装饰器同时承担了 JWT 解析、权限校验、审计日志记录、频率限制四种职责。这违反了单一职责原则，导致代码难以测试、维护和扩展。任何职责的变化都需要修改这个装饰器。
- **修复**: 拆分为多个独立的装饰器或中间件： ```python @jwt_required @require_permission('admin') @audit_log @rate_limit def my_view(request):     ... ``` 或者使用中间件模式，每个中间件只负责一个关注点。
