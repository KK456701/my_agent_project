## 历史案例

### 案例 1
- **日期**: 2026-05-18
- **来源 PR**: test
- **文件**: demo/sample_pr.py:285-301
- **描述**: get_config_with_cache 函数使用全局字典 _CONFIG_CACHE 缓存配置，但：1. 缓存永不过期，配置变更后不会更新。2. 无淘汰策略，内存可能无限增长。3. 多线程环境下存在竞态条件。
- **修复**: 使用 functools.lru_cache 或 cachetools.TTLCache 替代手动字典缓存。例如：from functools import lru_cache; @lru_cache(maxsize=128); def get_config(key): ... 或者使用 Redis 作为分布式缓存。
