## 历史案例

### 案例 1
- **日期**: 2026-05-19_095920
- **来源 PR**: Demo: 用户登录模块
- **文件**: demo/sample_pr.py:197-206
- **描述**: _TOKEN_CACHE 字典缓存了 Token 的验证结果，但没有设置过期时间。如果 Token 被吊销或用户权限变更，缓存中的旧数据仍会被使用，导致权限校验失效。
- **修复**: 1. 使用带 TTL 的缓存（如 cachetools.TTLCache）。2. 缓存键应包含 Token 的完整哈希。3. 对于高安全场景，每次请求都应验证 Token 的有效性，不缓存验证结果。
