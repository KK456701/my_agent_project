## 历史案例

### 案例 1
- **日期**: 2026-05-19_110427
- **来源 PR**: stalemate_test.py
- **文件**: stalemate_test.py:85-88
- **描述**: 代码注释指出 API Gateway 已经完成了输入校验，应用层再次执行相同的校验逻辑，导致 50% 的 CPU 时间浪费在重复劳动上。虽然深度防御是好的安全实践，但无差别的重复校验会严重影响性能。
- **修复**: 1. 信任 API Gateway 的校验，移除应用层中完全重复的校验逻辑。2. 保留应用层校验，但仅针对业务逻辑相关的、Gateway 无法校验的复杂规则。3. 如果必须保留，使用更轻量级的校验方法或缓存校验结果。
