## 历史案例

### 案例 1
- **日期**: 2026-05-18_104408
- **来源 PR**: Demo: 用户登录模块
- **文件**: demo/sample_pr.py:196-210
- **描述**: _TOKEN_CACHE 是模块级全局字典，被装饰器内部使用。这导致：1) 线程不安全，多线程环境下缓存数据可能不一致；2) 单元测试困难，因为测试之间共享状态，需要手动清理缓存；3) 缓存无过期机制，可能导致返回过期的JWT解析结果。这种设计使得代码难以预测和调试。
- **修复**: 1. 移除全局缓存，改为使用依赖注入方式传入缓存实例（如 Redis 或带 TTL 的本地缓存）。2. 如果必须使用本地缓存，使用 functools.lru_cache 或 cachetools 库，并设置 maxsize 和 ttl。3. 在测试中使用 mock 替换缓存。
